# Laila's Graduation Countdown

A GitHub Pages-ready live countdown for May 14, 2027 at 8:30 AM Eastern.

## Publish on GitHub Pages
1. Create a new public GitHub repository named `laila-graduation`.
2. Upload `index.html` and `laila-graduation-countdown.png` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will display the public site address after deployment.
